## 💻 Technical Experience & Projects
During my studies, I gained practical experience as a student research assistant. In this role, I:
- transcribed linguistic data for a machine learning project researching a [credible conversational pedagogical agent](https://hybrid-societies.org/en/research/d03/),
- contributed to a [command-line application for speech synthesis](https://github.com/njmiklos/pronunciation-dictionary-utils),
- developed a corresponding [graphical user interface](https://github.com/njmiklos/synthesis-gui).

🎓 My thesis explored how deep learning and foundation models can be applied to human activity recognition in smart homes using edge devices. I collected real-world data with a limited number of affordable, privacy-preserving ambient sensors and evaluated different approaches under the hardware constraints of a Raspberry Pi 3 in terms of accuracy and resource usage. See my [related repository](https://github.com/njmiklos/thesis-scripts-har-smart-home) for details.
